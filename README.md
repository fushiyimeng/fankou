# 双扣（方扣）

4 人两副牌 108 张的升级类玩法。单机版：你一个人打三个电脑玩家。

规则以项目目录里的 **《方扣卡牌.txt》** 为准（那是你手写的权威文档）。
规则怎么落到代码上、哪几处有歧义、我是怎么取的，都记在 **`docs/规则实现笔记.md`**。

**详细玩法说明**（规则讲透 + 打法思路）见 **`玩法说明.md`**。
程序里「帮助 → 规则说明」打开的是**简略版**，点下面的按钮能翻到同一份详细的——
那份 md 是构建时嵌进程序集的，改了文档程序里就跟着变，不会两边打架。

## 怎么玩

双击 `发布.bat` 打包，然后在
`src\FanKou.App\bin\Release\net10.0-windows\win-x64\publish\` 里找到 `FanKou.App.exe`，
拷到哪儿都能双击开玩（自带运行时，不需要装 .NET）。

**运行环境**：Windows 10（1809 及以上）或 Windows 11，64 位。别的系统不管。

开发的时候直接跑：

```bash
dotnet run --project src/FanKou.App
```

### 操作

- **叫主**：弹出对话框，列出你所有叫得出来的规格，并把要摆出来的明牌画在旁边
- **换底牌**：先把锅底那 8 张单独摊出来给你看，再合进手牌凑成 **33 张**，从这 33 张里挑 8 张扣回去。
  带蓝边的就是锅底那几张，带金色锁的是叫主的明牌（扣不了，文档第 56 行）。
- **出牌**：点牌选中，点「出牌」或按回车。选得不合规则会在状态栏告诉你哪里不对
- **提示**：按空格或点「提示」，会在合法出法里轮着给你看
- 菜单「卡牌样式」换牌面，「对手强度」切电脑的聪明程度，「牌局记录」看全程流水

### 对手强度

菜单「对手强度」里四档，随时切换、**马上生效**（不用重开一盘）：

| 档位 | 它会干什么 |
|---|---|
| **入门** | 只保证出牌合法，基本乱打，是给人练手的 |
| **简单** | 有一点自己的逻辑：看得懂分牌、认得出队友、知道省大牌 |
| **普通** | 在上面基础上**会记牌**：记得外面还剩什么，知道自己这一手会不会被压 |
| **困难** | 再加**推算**：从别人该给的花色没给够，推出哪家空门了、哪家没主牌了 |

实测强度（同一副牌打两遍、双方各坐一次东西，抵消发牌运气）：
简单档碾压入门档；**普通比简单强约 2.8%**；困难比普通强约 0.6%。
困难档确实在用推算做判断，但因为底层的出牌模型本身比较粗，
这点推算换来的胜率优势很小——想让它明显更强，得换思路（往前算一两步），不是加规则能解决的。

### 节奏

- **首局逐张发牌**：四个人各一张算一轮，**一轮 0.5 秒**，整副 25 轮共约 12.5 秒。
  这不是为了好看——**发牌途中就能叫主**：摸到小王加一张对口花色的级牌，当场就能叫，
  这就是"抢先叫主"。一次把牌发完，抢先叫主就没有意义了。
  牌没发完就叫的人直接坐庄，剩下的牌继续发完，然后他拿底牌换牌。
  嫌慢可以点一下屏幕或按任意键跳过（跳过时抢主照样保留，不会漏掉）。
  其它局是瞬间发完的。
- **每轮出完停 1.5 秒**：让你看清这一轮四家分别出了什么、谁赢了、分归谁。
- 叫主摆出来的明牌会一直摊在桌上，直到正式打出第一张牌才收回去。

这几个时间都在 `GameController.cs` 顶部，是三个常量，改数字就行。

### 方位

- **发牌顺时针**（东 → 南 → 西 → 北），**出牌逆时针**（东 → 北 → 西 → 南）。
- 屏幕上是罗盘方位：自己在下、对家在上、**东家在右、西家在左**。

## 换自己的卡牌样式

不用改程序，把图片丢进 `skins` 文件夹就行。详见 `skins\说明.txt`，简单说：

1. 菜单「卡牌样式 → 打开样式文件夹」
2. 建个子文件夹，比如 `skins\我的牌\`
3. 丢图片进去，文件名 `♠A.png` / `黑桃A.png` / `SA.png` / `spadeA.png` 都认
4. 菜单「卡牌样式 → 重新扫描」，选中它

**缺哪张牌都不会出错**——没图的牌自动用程序自带的画法补上，所以可以只做几张先试。

## 改规则

`rules.json` 里几个开关控制有争议的规则，改完重开程序即可（不用重新编译）：

| 开关 | 默认 | 意思 |
|---|---|---|
| `JokerPairChainIsTractor` | `true` | 小王对+大王对算不算连对（文档里你自己标了待问长辈） |
| `TractorUsesNaturalOrder` | `true` | 拖拉机内部级牌提不提权 |
| `PairFillerPolicy` | `TrumpOnlyWhenVoid` | 跟对子/拖拉机时什么时候必须垫主牌。默认空门（一张该花色都没有）才强制；`TrumpOnlyWhenPartial` 是文档第 69 行的旧规矩（有但凑不齐就垫），`TrumpOnly` 是一律垫，`AnyCard` 是随便补 |
| `TractorFollowPolicy` | `StructurePreserving` | 有连对是不是必须出连对 |
| `AllowNoTrumpCalls` | `true` | 开不开放小无主/大无主 |
| `AllowThrows` | `true` | 开不开放甩牌 |
| `AllowCounterCalls` | `true` | 开不开放反主 |

**王对算不算连对**（两张大王 + 两张小王）各地规矩不一样，各地都有人打，
所以做成了菜单「规则开关」里能直接点的开关，点完下一局生效，也会写回 `rules.json` 记住。

## 看它对不对

有个工具能让四个 AI 打给你看，每一轮谁出了什么、谁最大、捡了几分，都用中文打出来：

```bash
dotnet run --project tools/FanKou.Trace -- --seed 7 --hands --rounds 6
```

`--seed` 一样则结果完全一样，出问题可以拿种子复现。

跑测试：

```bash
dotnet test
```

## 现在做到哪了

**能玩了**：发牌、叫主/定主/小无主/大无主、**反主**、发牌途中抢先叫主、**抢主局**、庄闲分队、
出牌比大小（对子/拖拉机/**甩牌**/杀牌/垫牌）、捡分、8 张底牌换牌、底牌倍率结算、
升级掉级、多局连打、四档电脑玩家。

**顶牌**（甩牌里唯一必然合法的一种）：这门最大的两张 + 次大的一张。
打 5 的时候副花色是 `AAK`；打 K 的时候 K 被提成主牌、从副花色里拿掉了，所以变成 `AAQ`。
出牌时不算对子、算甩牌，只有同张数的全主牌能杀它。

**新加的几条，说一下规矩**：

- **反主**：只有**对手**能反（队友不能反），规格必须**比当前高**
  （叫主 < 定主 < 小无主 < 大无主），一直可以反到双大王为止。
  反主**只改主牌和谁拿底牌换牌**，不改庄闲、也不改谁先出牌——只有首局无庄的时候，
  谁最后反成功谁才是庄家。
- **甩牌**：同花色的散牌一起出（`AKQ`、`AKQJ`、`AAK` 这类）。前提是**这门里别人手上没有
  比你更大的牌**，线上由系统直接拦住（不做罚则）。跟牌时散牌不要求垫主。
- **抢主局**：上一局闲家拿了 85~114 分就触发。下一局是**发牌途中抢先叫主**，
  双方各用**自家**的级牌去抢；抢到的那队保住等级，没抢到的那队按保护规则掉级。
- 首局和抢主局都是**一张一张发牌**（每轮四人各一张 0.5 秒），因为"抢先叫主"就发生在
  发牌这一段。这个刻意**不提供跳过**——玩家局里要四个人都同意才跳得掉，反而麻烦。

**还没做**：目前规划里的都做完了。

## 项目结构

```
src/FanKou.Core/     规则引擎，纯逻辑，不依赖界面
  Cards/             牌、牌堆、排序、外部样式文件名的命名约定
  Levels/            等级序列（5→10→K→2→…→A）
  Trump/             主牌上下文、牌的次序与跟牌分组
  Combinations/      牌型识别（对子/拖拉机）与比大小
  Play/              跟牌合法性、候选出牌生成、单墩判定
  Bidding/           叫主查找
  Scoring/           计分、底牌倍率、升级判定
  Game/              一局/一盘的状态机
src/FanKou.Ai/       电脑玩家（随机 / 中等）与无界面对局驱动
src/FanKou.Ui/       绘制与控件（牌面、牌桌、手牌、对话框）
src/FanKou.App/      WinForms 主程序
tools/FanKou.Trace/  命令行规则自检工具
tests/               单元测试（含一万局无界面自打）
```
